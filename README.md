# port-i-email

Port-i 서비스의 이메일 발송 기능을 관리하는 저장소예요.

## 개요

이 저장소는 Port-i에서 사용하는 이메일 템플릿과 발송 관련 코드를 담아요.
아직 초기 단계라 구조와 사용법은 작업이 진행되면 채워 넣을 예정이에요.

## 디렉터리 구조

```
port-i-email/
└── README.md
```

## 시작하기

```bash
git clone https://github.com/smartm2m-plaform-team/port-i-email.git
cd port-i-email
```
